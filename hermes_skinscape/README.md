# Hermes Skinscape Bridge

A Home Assistant app that accepts an exported Hermes animated ASCII WebM, stores it persistently in `/data/media`, and presents it through Home Assistant ingress.

## Install

Add this repository URL in the Home Assistant Apps store, install **Hermes Skinscape Bridge**, start it, and enable **Show in sidebar**.

## Publish

Open **Skinscape** from the sidebar, choose a `.webm` exported by Hermes Skinscape, and select **Publish to Home Assistant**.
