HERMES // AGENTROPOLIS — CYBER TUI

A cyberpunk mission-control terminal experience for Hermes Agent. The real Hermes runtime stays untouched; the terminal presentation becomes a command center.

SKINS LAYOUTS CYBER TUI LIVE PREVIEW INSTALL DOCS
SKIN

Visual colors / branding

A Hermes skin is one YAML file that themes the CLI, TUI, and desktop — colors, branding, spinner. agentropolis-obsidian.yaml is the flagship: obsidian surfaces, cyan structure, red ops.

LAYOUT

Terminal composition

Layout profiles control how the terminal is composed: command-center (multi-panel mission control) or focus (conversation-first). Responsive breakpoints adapt to terminal width — no broken borders.

CYBER TUI

Interactive Hermes frontend

An actual Hermes TUI shell: the real conversation/transcript/input stays center-stage, wrapped in MISSION / TASKS / AGENTS / SYSTEM / APPROVALS / ACTIVITY / RECEIPTS panels. Real gateway events only — no fabricated telemetry.

Install

bash installer/install.sh       # builds, backs up, installs, sets HERMES_TUI_DIR
export HERMES_TUI_DIR=~/.hermes/cyber-tui
hermes --tui
# revert anytime:
bash installer/uninstall.sh
